# Данные аэропортов и маршрутов

Big Plane Radar обрабатывает ВПП на карте и города маршрута независимо:

- аэропорты и ВПП генерируются из OurAirports и компилируются во flash;
- города маршрута приходят из ADSBdb во время работы и кэшируются только в RAM.

Пользователю не нужно скачивать или генерировать эти данные.

## Настройки аэропортов и ВПП

На setup-странице доступны:

- `Show airports and runways` для включения или отключения слоя;
- `Nearest to radar center` для автоматического выбора ближайших аэропортов;
- `Airports shown` для выбора от одного до трёх аэропортов, по умолчанию одного;
- `Search radius` от 10 до 500 км;
- `Manual ICAO code` для выбора одного аэропорта, например `LEVC`.

Выбор пересчитывается после сохранения и перезагрузки. Глобальный каталог
просматривается один раз; при обычной отрисовке обрабатываются только выбранные
аэропорты и все их физические ВПП. ICAO-подпись аэропорта рисуется один раз.

## Динамические города маршрута

Ответ ADSBdb по callsign уже содержит IATA-коды, названия аэропортов и
municipality отправления и назначения. Прошивка сохраняет municipality прямо в
активном маршруте и запоминает до 128 соответствий `IATA -> город` в RAM LRU-кэше.

Кэш городов намеренно не записывается во flash. Он автоматически заполняется по
мере появления самолётов и становится пустым после перезагрузки. Если название
города недоступно, используется трёхбуквенный IATA.

Текст маршрута приводится к поддерживаемому дисплеем ASCII. Распространённые
латинские диакритические символы транслитерируются. Перед отрисовкой названия
измеряются реальным экранным шрифтом. Если строка не помещается, сначала
сокращается визуально более длинный город и получает `...`; процесс продолжается,
пока строка не влезет. Последний fallback — маршрут только из двух IATA-кодов.

## Источники данных ВПП

Каталог ВПП генерируется из публичного CSV-экспорта OurAirports:

- [страница загрузки OurAirports](https://ourairports.com/data/)
- [репозиторий данных OurAirports](https://github.com/davidmegginson/ourairports-data)
- [airports.csv](https://davidmegginson.github.io/ourairports-data/airports.csv)
- [runways.csv](https://davidmegginson.github.io/ourairports-data/runways.csv)

В header записываются URL и SHA-256 обоих CSV. Дата генерации не добавляется,
поэтому одинаковые входные файлы дают одинаковый результат.

## Обновление каталога ВПП

Нужны Python 3.10 или новее и доступ в интернет. Сторонние Python-пакеты не
требуются. Если установленный на macOS Python не видит системные CA-сертификаты,
скрипт автоматически использует системный `curl` с обычной TLS-проверкой.

Из корня репозитория выполните:

```sh
python3 scripts/update_airport_data.py
```

Команда скачает CSV в `.cache/ourairports/`, проверит их колонки и число строк,
после чего атомарно заменит:

```text
src/airport_catalog.h
```

В конце выводится число аэропортов и физических ВПП. При ошибке скачивания или
валидации существующий header не изменяется.

Повторная генерация из локального кэша без сети:

```sh
python3 scripts/update_airport_data.py --offline
```

Проверка header без его изменения:

```sh
python3 scripts/update_airport_data.py --offline --check
```

Использование заранее скачанных или архивных CSV:

```sh
python3 scripts/update_airport_data.py \
  --airports /path/to/airports.csv \
  --runways /path/to/runways.csv
```

Аргументы `--airports` и `--runways` всегда задаются вместе.

## Правила генерации

В каталог попадают открытые средние и крупные аэропорты хотя бы с одной доступной
незакрытой ВПП. Координаты хранятся с пятью знаками после запятой, направление —
в десятых долях градуса, длина ВПП — в метрах.

После обновления выполните:

```sh
python3 scripts/update_airport_data.py --offline --check
git diff --stat
CLEAN=1 bash build_arduino_cli.sh
```

Не редактируйте `src/airport_catalog.h` вручную. Исправляйте генератор или
обработку исходных данных, затем пересоздавайте header.

## Диагностика

Если аэропорт не найден автоматически, увеличьте радиус и проверьте координаты
радара. Малые аэродромы и вертолётные площадки намеренно исключены.

Если ручной режим сообщает `ICAO code not found`, проверьте ICAO и обновите
данные OurAirports.

Если маршрут показывает IATA вместо городов, ADSBdb не вернул подходящие
municipality, а в RAM-кэше этих городов ещё не было.
